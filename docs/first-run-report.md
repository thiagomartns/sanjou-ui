## 4. Pendências

- **Aviso cosmético no Vitest/Storybook:** `Failed to resolve dependency: @mdx-js/react, markdown-to-jsx, present in client 'optimizeDeps.include'`. As entradas "cruas" são injetadas pelo próprio `@storybook/addon-docs` (`optimizeViteDeps`) e não podem ser removidas pelo `viteFinal`. `@mdx-js/react` já é pré-empacotado pela forma aninhada. `markdown-to-jsx` é devDependency do addon (vem embutida no `dist`) e não é carregada em runtime. Não há impacto funcional.
- **Axe só roda no tema light nos testes.** O dark foi verificado na renderização (passo 9), mas não com axe. Sugestão para o futuro: um segundo projeto no Vitest com `globals: { theme: 'dark' }`. Não implementei porque está fora do escopo de "deixar verde".
- **`next build` com `Retrying 1/3...`:** na primeira execução, o `next/font/google` repetiu o download das fontes Geist. Não se repetiu nas execuções seguintes, e o Google Fonts respondia normalmente. É uma dependência de rede no build; se o CI for instável, considere `next/font/local`.
- **Docs gerada pelo docgen:** o controle `variant` aparece como `string`, não como a união do `cva`. Isso é cosmético.
- **Autoria dos commits:** usei o `user.name`/`user.email` do git global desta máquina. Confira se é a identidade que você quer neste repositório.
